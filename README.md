# Conway's Game of Life

A lightweight, browser-based implementation of Conway's Game of Life built with vanilla JavaScript, HTML5 Canvas, and an Express backend.

# Features

Modular Logic: Pure ES Modules handling cell evolution with support for toroid (wrap-around) rules.

HTML5 Canvas: High-performance real-time rendering in the browser.

Auto-Launch Server: Powered by Express to spin up and open the local app instantly.

# Getting Started

1- Install dependencies:

npm install

2- Run the application:

node main.js
